# Class Rep Quick Start Guide

## DIT Forms — Handout Tracker

---

### 1. Getting Started

**URL:** https://dit-tracker.vercel.app/

**Install as App:**
- **iPhone:** Tap Share → "Add to Home Screen"
- **Android:** Tap ⋮ → "Install App" or "Add to Home Screen"

**Login:** Use the credentials your Admin gave you.

---

### 2. Your Dashboard

When you log in, you see your dashboard with:
- **Your Scope** — the class and term you're assigned to (e.g., DIT-2026-2 / 2026-S2)
- **New Submission** — record a student handout
- **Handout Orders** — view and manage invoices
- **Quick Stats** — pending orders, paid count

---

### 3. Recording a Handout

1. Tap **"New Submission"** or go to the public form link
2. Enter the student's **full name** and **ID number**
3. Fill in the handout items:
   - Course ID (e.g., ENT101)
   - Item name
   - Quantity
   - Unit price (GH₵)
4. Set the **date given out**
5. Tap **Submit**

You'll hear a confirmation sound. The system auto-creates an invoice.

---

### 4. Recording a Payment

1. Go to **Handout Orders**
2. Find the unpaid invoice (amber badge)
3. Tap **"Mark Paid"**
4. Enter:
   - Amount
   - Method: Cash, Bank, or Mobile
   - Reference (optional)
5. Confirm

The status changes to **Paid** (green badge).

---

### 5. Downloading an Invoice PDF

1. Go to **Handout Orders**
2. Find the order
3. Tap the **📄 document icon**
4. The PDF downloads to your device
5. Share via WhatsApp, print, or save

---

### 6. Exporting Data

Tap **"Export Invoices"** at the top of the Handout Orders page to download a CSV file with all invoices for your class. Send this to the finance department.

---

### 7. Rules to Remember

| Rule | Why |
|---|---|
| You can only see YOUR class | Scope is locked by Admin |
| Students can't get the same course twice | System blocks duplicates |
| You can't delete orders | Contact Admin for corrections |
| You CAN mark orders as paid | That's your main job |
| Offline: you can search students | But submissions need internet |

---

### 8. Common Issues

| Problem | Solution |
|---|---|
| Can't log in | Ask Admin to reset your password |
| Student not found | Their ID might not be in the system — ask Admin to import |
| "Already submitted" error | This student already has this course this term |
| Page looks broken | Pull down to refresh, or close and reopen the app |
| No sound on submit | Check your phone isn't on silent |
