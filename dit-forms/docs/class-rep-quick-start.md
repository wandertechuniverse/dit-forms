# Class Rep Quick Start Guide
**DIT Tracker Mobile App | v1.0 Production Release**

## 1. Getting Started
- **Access:** Open `https://dit-tracker.vercel.app/` on your phone.
- **Install PWA:** Tap **Share (iOS)** or **Menu ⋮ (Android)** → **"Add to Home Screen"**. This removes the browser bar and makes it feel like a native app.
- **Login:** Use the email and password provided by Admin. You will only see data for your assigned Class & Term.

## 2. Recording Handouts (Submissions)
1. Tap **"New Submission"** on your Dashboard.
2. Enter Student **Full Name** and **ID Number**. The system auto-matches if they exist in your class list.
3. Fill in the form fields. For **Handout Items**, use the table to add:
   - Course ID (e.g., ENT101)
   - Item ID (e.g., HND-001)
   - Quantity & Unit Price (GH₵)
4. Tap **Submit**. Listen for the success sound/haptic feedback.
5. **Duplicate Block:** If a student already has this course handout this term, the system will block it automatically.

## 3. Recording Payments
1. Go to **Handout Orders** and find an unpaid invoice.
2. Tap **"Pay"** or use the Quick Action button.
3. Enter Amount, Method (Cash/Bank/Mobile), and Reference.
4. Confirm. Status updates instantly to "Paid" or "Partially Paid".

## 4. Important Rules
- **No Deletions:** You cannot delete submissions or invoices. Contact Admin for corrections.
- **Scope Lock:** You cannot switch classes/terms. Ask Admin to assign additional scopes if needed.
- **Offline Mode:** Student lists are cached. You can search offline, but submissions/payments require internet.

## 5. Troubleshooting

| Issue | Fix |
|---|---|
| Can't login | Check credentials; contact Admin if locked out |
| "Network Error" | Check internet connection; app caches student list for offline search |
| Duplicate error | Student already has this course handout this term |
| Payment not recording | Ensure amount is less than or equal to remaining balance |
